Biocomputing hackathon

Can a dish of neurons
fly a drone?

We wired 64 simulated neurons into a closed loop with a drone flying through a 3D-scanned living room.

~15 s. Living neurons on a chip (Cortical Labs CL1) can be stimulated and read. We ask: can they steer something in 3D? Today: on the CL SDK simulator, same code runs on the real chip.
The trick

We never train the neurons.
We only learn to read them.

The neurons

Left exactly as they are. They mix whatever we send in, nonlinearly and noisily.

The readout

One small table of weights: spikes in, steering out. Trained in under a second.

This is called reservoir computing. On real tissue you can't rewire the cells, so this is the approach that transfers.

~15 s. Key message: the network is a fixed black box. All the learning is in a tiny linear readout on top.
How it works · 100 times per second

A closed loop

~20 s. Walk the boxes left to right. Distance becomes pulse rate, the same way the DishBrain Pong experiment encoded the ball.
The electrode map

The dish sees a panorama

Middle 32 electrodes: input

One per lidar ray. Each column is a tilt (up to down), each row a direction.

Outer 27 electrodes: output

Never stimulated. Any steering signal here had to travel through the network.

~20 s. Crossed-out corners are dead electrodes on the real chip. The fair test is the outer ring: no direct input reaches it.

The network flies better than the raw sensor

One simulated run (LIF network, seed 42). Steering prediction: all neurons R² 0.64 vs raw lidar 0.40, because the neurons add the nonlinearity a linear readout lacks.

~20 s. Two points: all neurons beat raw lidar on steering, the reservoir effect. The outer ring alone is weak but still 2.5× better than a fixed command. Simulator, not tissue: next step is the CL1.
